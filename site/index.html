Inside the model +

The symmetrized fields obey H Y = k²Y, with H = −∂²x + V. The dimensionless radius is r > 1, the mouth radius is set to one, and L = ℓ(ℓ + 1).

M = m²S is the Schwinger screening parameter. It is not the black-hole mass or a fermion rest mass. The result uses the published extremal-mouth approximation and lowest-Landau-level matter response.

For the attraction theorem, B is bounded, compactly supported and positive semidefinite, with positive overlap ∫u0†Bu0 dx. Whether a physical correction has this form is a separate question.
